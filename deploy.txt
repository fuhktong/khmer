 4. CHECK YOUR SENTENCES ARE VALID JSON BEFORE PUSHING
---------------------------------------------------------------------

 A single missing comma breaks the whole game. This checks the file
 and confirms every Khmer word exists in your vocabulary list:

cd "/Users/dustintaylor/Documents/programming/mywebsites/035 khmer/khmer"
python3 -c "
import json
w=json.load(open('khmerwords.json')); s=json.load(open('sentences.json'))
lex=set()
for x in w:
    lex.add(x['khmer']); lex.update(x.get('variants',[]))
bad=[(q['id'],t) for q in s for t in q['khmer'] if t not in lex]
print(len(s),'sentences  |  unknown words:', bad or 'none')
"

---------------------------------------------------------------------
 6. ADDING NEW SENTENCES — the format
---------------------------------------------------------------------

 Add to sentences.json, inside the [ ] brackets, comma between each:

  {
    "id": 51,
    "level": 2,
    "english": "I will go to school tomorrow.",
    "khmer": ["knyom", "nung", "dtow", "sala-rean", "sa-aik"],
    "alsoAccept": [["sa-aik", "knyom", "nung", "dtow", "sala-rean"]],
    "note": "Time words can lead the sentence or trail it."
  }

  id          any number, just keep them unique
  level       1 = short,  2 = negation/tense/questions,  3 = longer
  khmer       the correct word order, one word per tile
  alsoAccept  OTHER orders that are also correct. Leave as [] if none.
              IMPORTANT: if a sentence has more than one valid order and
              you leave this empty, the game will mark correct answers
              wrong. Time words in particular can usually move.
  note        optional. Only shown after a correct answer.

 The last entry before the closing ] must NOT have a comma after it.
 Run the check in section 4 after editing.
